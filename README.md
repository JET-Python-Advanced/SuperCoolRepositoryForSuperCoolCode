# JET - Python Advanced 2026 - Unterlagen
Dieses Repository enthält sämtliche Unterlagen, die im Laufe des Kurses bereitgestellt werden. Die Materialien werden laufend aktualisiert.

## Ordnerstruktur

- **code/**  
  Beispielprogramme, Erklär-Code und Demonstrationen aus dem Unterricht.

- **slides/**  
  Präsentationen und Folien als PDF.

- **data/**  
  Übungsdaten für das fortlaufende Beispiel
  
- **exercises/**  
  Wöchentliche Übungsblätter (freiwillig)
  
- **exercises/solutions/**  
  Musterlösungen zu den Übungsblättern

## Wie Sie dieses Repository verwenden

- Sie können jederzeit auf alle Materialien zugreifen.  
- Bei neuen Unterrichtseinheiten wird der passende Ordner aktualisiert.

## Übungsblätter und Lösungen

- Die Übungsblätter sind freiwillig und werden nicht abgegeben bzw. bewertet.
- Jedes Übungsblatt besteht aus zwei Teilen:
  - Teil A: Kleinere Aufgaben zu den aktuellen Themen
  - Teil B: Medienbibliothek: fortlaufendes Projekt, welches über den gesamten Kurs hinweg wächst
- Die Musterlösungen lade ich immer kurz vor der Folgeeinheit hoch. Zu Beginn jeder Einheit besprechen wir diese kurz.

## Hinweise

- Änderungen an den Materialien erscheinen sofort – Sie müssen nichts installieren.  
- Wenn Sie Dateiänderungen nicht sehen, aktualisieren Sie die Seite.
